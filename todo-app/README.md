# My Tasks - 데일리 할 일 관리 웹 앱

**My Tasks**는 매일 10~20개의 할 일을 효율적으로 관리할 수 있도록 설계된 직관적이고 가벼운 웹 애플리케이션입니다. 외부 라이브러리 없이 순수 HTML, CSS, JavaScript로 구현되었으며, 모바일과 데스크톱 화면 모두에 최적화된 반응형 뷰를 제공합니다.

---

## 1. 주요 기능

* **할 일 등록 / 수정 / 삭제**:
  * `Enter` 키 또는 [추가] 버튼으로 즉시 등록
  * 할 일 텍스트를 **더블클릭**하여 인라인 수정 (`Enter` 저장, `ESC` 취소)
  * 우측 `×` 버튼으로 간편 삭제
* **완료 체크 & 진행률 바**:
  * 체크박스 토글 시 취소선 및 투명도 변경
  * 완료 수치와 백분율을 시각적 게이지 바(부드러운 애니메이션)로 실시간 안내
* **카테고리 분류 및 필터링**:
  * 업무(`#4A90E2`), 개인(`#27AE60`), 공부(`#8E44AD`) 3종 태그 표시
  * 상단 필터 탭(`전체`, `업무`, `개인`, `공부`) 클릭 시 즉시 필터링
* **검색 및 편의 기능**:
  * 입력 즉시 목록을 걸러주는 **실시간 검색** 기능 (카테고리 필터와 연동)
  * 완료된 할 일을 한 번에 정리하는 **완료된 항목 삭제** 버튼 (확인창 지원)
  * 표시할 항목이 없을 때 나타나는 빈 상태 안내 메시지
* **데이터 영구 저장**:
  * 브라우저 `localStorage`를 사용하여 새로고침하거나 브라우저를 닫아도 데이터가 유지됨
* **반응형 2열 / 1열 레이아웃**:
  * **데스크톱(≥768px)**: 최대 1000px 너비, 좌측(입력 및 진행률) / 우측(목록 및 검색) 2열 분할
  * **모바일(<768px)**: 한 손 조작에 최적화된 1열 카드 레이아웃

## 2. 실행 방법

별도의 빌드나 의존성 설치 과정 없이 즉시 실행할 수 있습니다.

### 방법 1. 브라우저에서 직접 열기 (가장 간단)
* `index.html` 파일을 더블클릭하거나 사용하는 웹 브라우저(Chrome, Safari 등) 창에 드래그 앤 드롭합니다.

### 방법 2. 로컬 웹 서버 구동 (권장)
터미널에서 프로젝트 디렉토리로 이동 후 간이 웹 서버를 실행합니다:
```bash
# 프로젝트 디렉토리로 이동
cd /Users/yuminkim/.gemini/antigravity/scratch/todo-app

# 파이썬 로컬 서버 실행 (포트 8085)
python3 -m http.server 8085
```
실행 후 웹 브라우저에서 **`http://localhost:8085`**에 접속합니다.

## 3. 파일 구조

```text
todo-app/
├── index.html        # 웹 애플리케이션 화면 마크업 (시맨틱 & 2열 레이아웃)
├── style.css         # 반응형 스타일시트 (768px 분기, 카테고리 컬러, 모바일 터치 최적화)
├── script.js         # 데이터 저장(localStorage), C/R/U/D 및 검색/필터 비즈니스 로직
├── README.md         # 사용자 가이드 및 프로젝트 소개 문서
├── GEMINI.md         # 단계별 개발 진행 내역 및 작업 로그
└── backup/           # 안정적인 복원을 위한 이전 버전 원본 백업
    ├── index.html
    ├── style.css
    └── script.js
```
